## ✨ Overview

Limat POS is built for speed and reliability, enabling cashiers to process orders rapidly while automatically keeping inventory in check.

## 🚀 Key Features

- ⚡ **Rapid Barcode Checkout**: Lightning-fast cashier interface with robust barcode scanner support.
- 📦 **Real-time Inventory Tracking**: Automatic stock deduction and low-stock alert warnings for store managers.
- 🧾 **Thermal Receipt Printing**: fully compatible with standard 80mm thermal receipt printers.

## 🛠️ Setup Instructions

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shetesfa/limat_pos_final.git
   ```
2. **Database Import**:
   - Import `database.sql` into MySQL.
3. **Launch Application**:
   - Access the system at `http://localhost/limat_pos_final/`.
